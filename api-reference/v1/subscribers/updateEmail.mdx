---
title: 'Update Email'
---

"A customer is always a king" (Pure fact though)

So whenever any of them change their email, use this endpoint to update it into taag too:

```method: POST
https://api.taag.cc/v1/subscribers/updateEmail
```

## Authorization

Same here the **secret key** is required (because of a server side api call) and pass it in the "authorization" as its value like this:

```bash
Authorization: taag_sk_xxxxxxxxx
```

> Don't forget the mode you are in, which is important to keep in mind and use the coreesponding key.

---

## Request body

```bash
{
	"subscriberId": "f3a5e5afda82acd2569415e869193d9d",
	"newEmail": "janedoe@gmail.com"
}
```

<ResponseField name="subscriberId" type="string" required>
    Use the subscriberId you received from us on [get subscribers]("/getSubscribers") endpoint
</ResponseField>
<ResponseField name="newEmail" type="email" required>
    A new email of the subscriber 
</ResponseField>

---

## Response

When successful you will receive this response:

```bash
    {
        "message": "Subscriber email updated successfully",
        "mode": "TEST",
        "subscriber": {
            "email": "janedoe@gmail.com",
            "subscriberId": "f3a5e5afda82acd2569415e869193d9d"
        }
    }
```
