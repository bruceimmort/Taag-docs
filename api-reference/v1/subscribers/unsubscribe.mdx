---
title: "Unsubcribe"
---

## Use case
Is it time to unsubscribe a user from using your service ? 

Hit this endpoint right here:

```method: POST
https://api.taag.cc/v1/subscribers/unsubscribe
```

---

## Request body

```bash
{
	"subscriberId": "f3a5e5afda82acd2569415e869193d9d"
}
```

<ResponseField name="subscriberId" type="string" required>
    Use the **subscriberId** you received to let taag know which user precise is unsubscribing
</ResponseField>

---

## Response

After the user is unsubcribed you will immediately get this resonse:

```bash
    {
        "message": "Subscriber unsubscribed successfully",
        "mode": "TEST",
        "subscriber": {
            "email": "janedoe@gmail.com",
            "subscriberId": "f3a5e5afda82acd2569415e869193d9d",
            "status": "UNSUBSCRIBED",
            "unsubscribedAt": "2025-08-26T19:48:57.918Z"
        }
    }
```
