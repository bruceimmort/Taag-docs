title: 'Get plans'
openapi: 'GET /plans/all'
---

<Danger>This endpoint is no longer supported.</Danger>

Use this endpoint to retrieve all plans for your project. This endpoint returns both active and archived plans, separated for easy management.

```method: GET
https://api.taag.cc/v1/plans/all
```

## Authorization
All you need is to include your **secret key** as a value of **authorization** in the header and hit the endpoint above.

```bash
Authorization: taag_sk_mode_xxxxxxxxx
```
<ParamField path="Authorization" type="string" required>
  Use the secret key that matches the mode you are in TEST or LIVE. Keys with `_test_` fetch TEST plans, keys with `_live_` fetch LIVE plans.
</ParamField>

<Note>

- **Active plans** can be used for new checkouts and subscriptions.
- **Archived plans** are shown for reference but cannot be used for new subscriptions.
- Existing subscribers to archived plans will continue to be charged.

</Note>
