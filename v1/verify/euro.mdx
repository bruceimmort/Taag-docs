---
title: 'Verify euro'
openapi: 'GET /verify/euro'
---

You will use this API to check if a specific country code is supported for **EUR currency** payments. This is a public endpoint that does not require authentication.

Here is the API endpoint:

```method: POST
https://api.taag.cc/v1/verify/euro
```

## Request body

```bash
{
    "countryCode": "FR"
}
```

## Response

As a response to your request, you will receive a JSON object indicating whether the country is supported for EUR payments.


<AccordionGroup>
  <Accordion title="Supported">
    When the country is supported, this will be your response:
    
    ```bash
    {
        "success": true,
        "supported": true,
        "countryCode": "FR",
        "countryName": "France",
        "category": "EU/EEA SEPA Countries",
        "currency": "EUR"
    }
    ```
  </Accordion>

  <Accordion title="Unsupported">
    When the country is not supported, this will be your response:

    ```bash
    {
        "success": true,
        "supported": false,
        "countryCode": "US",
        "message": "This country code is not supported for EUR currency",
        "description": "Please check our documentation for the full list of supported SEPA/Euro countries"
    }
    ```
  </Accordion>

  <Accordion title="Missing">
    When the country code is missing, this will be your response:

    ```bash
    {
        "success": false,
        "error": "Missing country code",
        "description": "countryCode is required in the request body"
    }
    ```
  </Accordion>
  <Accordion title="Error">
    When the country code length is invalid, this will be your response:

    ```bash
    {
        "success": false,
        "error": "Invalid country code length",
        "description": "countryCode must be exactly 2 characters (e.g., \"FR\", \"DE\", \"IT\")"
    }
    ```
  </Accordion>
</AccordionGroup>

We support 44 countries across three categories for EUR currency payments:
